# TANZAN Portfolio

渥美聡一郎 / TANZAN Books のオリジナルWordPressポートフォリオテーマです。MOVE FREE Level 3 最終課題として制作しています。

## 使用技術
HTML、CSS、JavaScript（標準DOM API）、PHP、WordPress、Contact Form 7。
生成AIを制作支援に使用しています。実装内容を説明できるよう、コードの理解・確認を進めています。

## 実装内容・こだわり
- Hero、About、Skills、Works、Contactの構成。書籍と地域活動を表現した配色と本のCSSアニメーション。
- PC・スマホ対応。動きを抑える設定への配慮。
- テンプレート分割、wp_head / wp_footer、wp_enqueue_scriptsによるCSS・JS読み込み。
- wp_nav_menuによる管理画面から編集可能なメニュー。
- プラグインに頼らないカスタム投稿タイプ works、アイキャッチ、詳細用カスタムフィールド。
- WP_Queryで公開済み実績を最新順に最大6件表示。
- dialog要素による詳細モーダル。閉じるボタン、Esc、閉じた後のフォーカス復帰。
- 200px以上スクロールすると現れるページ先頭ボタン。
- Contact Form 7との連携。
- 出力内容に応じたesc_html、esc_attr、esc_url等の使用。保存時のnonce・権限確認、入力値の検証とサニタイズ。

## 導入手順
1. WordPressに本テーマをインストールして有効化します。リポジトリのルートがテーマ本体です。
2. 管理画面の「制作実績」から投稿を追加し、本文・アイキャッチ・使用技術・制作期間・担当範囲・公開URLを設定します。
3. 「外観 → メニュー」でメニューを作成し、ヘッダーナビゲーションに割り当てます。セクションへのリンク例はサイトトップURLに #about / #skills / #works / #contact を付けます。
4. Contact Form 7をインストール・有効化してフォームとメール設定を作成します。
5. 「外観 → カスタマイズ → お問い合わせフォーム」にフォーム編集URLのpost=に続く数値IDを入力して公開します。
6. 実行環境に応じてメール送信を設定し、送信先で実際の受信を確認します。メール設定・投稿データはテーマファイルには含まれません。

## 設定時に確認した課題と対応
### フォームの配置
フォームを作成するだけでなく、テーマ側へのID設定が必要でした。フォーム編集URLの数値IDをカスタマイザーに設定し、トップページのContactに表示されることと実際の受信を確認しました。

### WordPressテーマの公開環境について
当初はGitHubにファイルをアップロードすれば、そのままサイトを表示できると考えていました。しかし、GitHubでのソースコード管理と、WordPressを実行する環境は別であり、GitHub PagesではPHPを実行できないことを学びました。MAMP上のWordPressでテーマを動作させ、GitHubはソースコードの提出・共有に使用する形に整理しました。これはコードのエラーではなく、公開環境への理解に関する課題でした。

### 画像サイズの調整
制作実績に掲載する画像のサイズを調整し、カード内で見やすく表示する点に苦労しました。テーマには表示領域の縦横比を4:3にそろえ、画像をobject-fit: coverで収める指定があります。この指定では画像の一部が切り取られるため、画像全体を見せる必要がある場合には表示方法の検討が必要だと学びました。PCとスマホ幅での表示を確認しました。個別の元画像サイズや変更値は記録していません。
