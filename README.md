# TANZAN Portfolio

MOVE FREE Level 3 課題として制作したポートフォリオです。WordPressテーマと静的版を含みます。制作には生成AIを使用しています。

## フォルダ構成

- `tanzan-portfolio/`：WordPressテーマ本体。PHPテンプレート、`style.css`、`functions.php`、`assets/` を含みます。
- `static/`：静的版。`index.html`、`style.css`、`main.js` を含みます。WordPressテーマではありません。
- `docs/contact-form7.txt`：Contact Form 7の設定用テキスト。
- `README.md`：この説明書。

## 静的版とWordPress版

静的版は `static/index.html` をブラウザで開いて確認できます。メインビジュアルはCSSで描いた本のイラストです。制作実績はHTMLに書かれた3件のサンプルで、フォームは表示と入力確認の見本です。メールは送信されません。内容の変更にはファイルの編集が必要です。

WordPress版は `tanzan-portfolio/` のテーマをWordPressで動かします。メインビジュアルの背景はカスタマイザーで画像を指定できます。未指定時は同梱の `assets/library-bg.svg` を表示します。制作実績は管理画面から登録し、公開済みのものを新しい順に最大6件表示します。フォームはContact Form 7とメール送信環境の設定が必要です。両版の本文やビジュアルは同一ではありません。

## WordPress版の導入

1. PHP・データベースを使える環境にWordPressをインストールします。テーマの `style.css` には WordPress 6.3以上、PHP 8.0以上と記載しています。環境の互換性は利用前に確認してください。
2. リポジトリ内の **`tanzan-portfolio` フォルダそのもの**をWordPressの `wp-content/themes/` にコピーし、`wp-content/themes/tanzan-portfolio/style.css` が存在する状態にします。リポジトリ全体や `static` はテーマ本体ではありません。
3. WordPress管理画面の「外観 → テーマ」で「TANZAN Portfolio」を有効化します。トップページに表示されない場合は「設定 → 表示設定」のホームページの設定を確認します。
4. 「制作実績」から投稿を作成し、タイトル、本文、アイキャッチ画像、使用技術、制作期間、担当範囲、公開URLを必要に応じて入力して公開します。
5. 「外観 → メニュー」でメニューを作成し、ヘッダーナビゲーションに割り当てます。トップページ内のリンクにはサイトURLの後に `#about`、`#skills`、`#works`、`#contact` を使用できます。メニュー未設定時はテーマの既定メニューが表示されます。
6. Contact Form 7をインストール・有効化し、フォームとメール設定を作成します。`docs/contact-form7.txt` を設定時の参考にできます。
7. 「外観 → カスタマイズ → お問い合わせフォーム」にフォーム編集画面のURLにある `post=` の後の数値IDを設定して公開します。メール送信環境を設定し、テスト送信と受信を確認してください。未設定の場合はメールアドレスを表示します。
8. 背景画像は「外観 → カスタマイズ → メインビジュアル」から変更できます。

投稿データ、フォームの設定、メール設定、カスタマイザーの設定はテーマファイルには含まれません。GitHub PagesはPHPを実行できないため、WordPress版の実行には使用できません。パスワードや `wp-config.php` はリポジトリに含めません。

## 実装の概要

- WordPressのカスタム投稿タイプ `works` と、詳細用カスタムフィールド。
- 公開済みの制作実績の一覧、ダイアログによる詳細表示。
- テーマのメニュー、CSS・JavaScriptの読み込み、Contact Form 7との連携。
- 保存時のnonce・権限確認、入力値のサニタイズと出力時のエスケープ。
- PC・スマートフォン向けの表示と、動きを抑える設定への対応。
